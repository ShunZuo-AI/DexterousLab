图片用于本地README视觉展示，不是本项目仿真截图，不代表硬件合作、厂商背书或已支持所有图片中的硬件版本。

## 历史官方图片合成封面

此前合成封面为 `../dexterouslab-reference-style.png`（3000×1800）。参考用户提供的 `901254c4-a89b-47dc-847e-b23e71e66e24.png` 的中央主体、两侧手型、浅蓝玻璃光带及深蓝斜体标题。中央主体采用Tesollo DG-5F-M官方商品图，另17张商品图围绕展示，每张只使用一次。当前README改用用户原图作为概念封面，详见 [视觉素材说明](../README.md)。本目录的18张官方商品图及其来源继续独立保留。

未复制参考图中的品牌标识或将其手型身份当作事实；厂家名称仅标注真实已收集图片。封面能力文案限定为Multi-hand assets、Isaac Lab simulation、Traceable experiments。透明视窗内使用本项目真实失败实验的闭合阶段截图，玻璃光带与立方体属于视觉装饰。

## 原图与加工范围

`originals/` 保存下载图片解码后的无损PNG副本；原始网络响应SHA256与本地PNG SHA256分别记录，不混为一个值。Barrett商品图来自官方BH8-282 PDF中的嵌入JPEG，PDF副本也保留。

`cutouts/` 保存展示副本。加工限于透明边缘裁剪、尺寸标注外部区域移除、L20商品前景分割、缩放、旋转和背景排版；不改变商品配色、不生成新的手部结构、不移除产品上的品牌标识。构图中的浅蓝立方体为示意图形。

ORCA官网当前商品为v2.1，而项目已验证资产是v1；Wuji Hand2商品图也不用于判定2.1/2.2具体仿真版本。官方商品图片数量与项目资产验证数量分别统计。
