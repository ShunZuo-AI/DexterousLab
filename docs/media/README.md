# README 视觉素材

## 艺术字与图标排版

`readme-style/` 提供品牌艺术字、双语章节标题、线条图标、导航按钮、数字概览与页脚。全部为自包含SVG，文字转换为字形路径，支持在GitHub直接显示；正文与命令保持可复制文本。[设计规范、参考项目与生成方式](../readme-visual-design.md)。
